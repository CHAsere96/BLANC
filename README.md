## 이미 올린 저장소를 이 버전으로 바꾸기

1. 이 zip을 풉니다.
2. GitHub 저장소에서 Add file → Upload files
3. index.html, css/, js/, images/, favicon.svg, README.md 를 다시 올립니다.
4. 같은 파일은 덮어쓰기됩니다.
5. Commit 후 1분 뒤 사이트를 새로고침합니다.
